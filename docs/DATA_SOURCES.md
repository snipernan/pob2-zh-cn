# 翻译来源与数据边界

数据快照日期为 **2026-09-14**，当时核验核心为 **0.23.1**、当前树为 **0.5**。网页或交易接口的新内容经过对应核心版本核验后纳入。

## 来源优先级

1. 已核验腾讯国服术语，优先保留原文。
2. 缺失内容使用 [流亡 2 编年史](https://poe2db.tw/cn/) 的简体中文与英文对应页。
3. 少量旧版或明显来源文字问题经过人工校对，明确标注为人工校对并记录依据。
4. 待核验内容保留英文，新增译文按稳定身份和完整语义核对后收录。

| 数据 | 文件 | 配对依据 |
| --- | --- | --- |
| 技能 | `data/skills-cn.json` | [国服目录](https://poe.game.qq.com/api/trade2/data/items)中的精确名称，结合 PoB ID 和经核验的英文身份 |
| 通用词缀 | `data/affixes-cn.json` | [国服词缀](https://poe.game.qq.com/api/trade2/data/stats)与[国际服词缀](https://www.pathofexile.com/api/trade2/data/stats)的完整 stat ID |
| 国服天赋 | `data/tree-cn.json` | 节点 ID、英文身份和官方完整词条 |
| 编年史天赋补充 | `data/tree-poe2db-cn.json` | [天赋树](https://poe2db.tw/cn/passive-skill-tree/)的节点／内部 ID、版本和完整效果；替代选项另行核验 |
| 装备 | `data/equipment-*.json` | [传奇](https://poe2db.tw/cn/Unique_item)、基底分类和详情页中的英文身份、基底及完整词缀块 |
| 树覆盖输入 | `data/inputs/tree-0_5.json` | 从原核心 tree.json 提取名称、效果及装饰／职业起点标识 |

## 可追溯信息

JSON 保留来源 URL、快照摘要、`sourceIds`、`verification`、适用版本、槽位映射和人工修订原因。不同数据批次字段命名稍有不同，编译器会验证本批使用的字段。`data/source-manifest.json` 是本仓库源输入文件的摘要清单。

来源字段里的 `research/...` 路径用于追溯历史采集缓存，来源 URL 与摘要记录当时的采集依据。本仓库通过审核后的映射提供**运行词典的可复现离线构建**。

## 当前核验范围

- 1282 条界面译文；719 个 PoB 技能 ID 对应 718 个不同国服名称。
- 3427 个通用词缀模板；额外收录 672 个装备专用模板。
- 4540 个当前树非装饰节点名称，包含基础效果及版本限定的替代选项。
- 1768 个基底；447 个传奇名称与基底组合；287 个增幅器、26 种液化情感及 32 个类别。

这些数字对应上述快照及核心版本的收录／核验范围。测试产生的运行时覆盖输出保存在本地，用于核对实际加载情况。
