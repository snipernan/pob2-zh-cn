# 翻译来源与数据边界

数据快照日期为 **2026-09-14**，当时核验核心为 **0.23.1**、当前树为 **0.5**。网页或交易接口的新内容不自动视为适用于此核心。

## 来源优先级

1. 已核验腾讯国服术语，优先保留原文。
2. 缺失内容使用 [流亡 2 编年史](https://poe2db.tw/cn/) 的简体中文与英文对应页。
3. 少量旧版或明显来源文字问题经过人工校对，单独记录，不称为官方原句。
4. 没有可靠依据则保留英文，不做繁简转换或全局模糊匹配。

| 数据 | 文件 | 配对依据 |
| --- | --- | --- |
| 技能 | `data/skills-cn.json` | [国服目录](https://poe.game.qq.com/api/trade2/data/items)中的精确名称，结合 PoB ID 和经核验的英文身份 |

| 树覆盖输入 | `data/inputs/tree-0_5.json` | 原核心 tree.json 的名称、效果、装饰／职业起点标识；不含图像或树布局 |

## 可追溯信息

JSON 保留来源 URL、快照摘要、`sourceIds`、`verification`、适用版本、槽位映射和人工修订原因。不同数据批次字段命名稍有不同，编译器会验证本批使用的字段。`data/source-manifest.json` 是本仓库源输入文件的摘要清单。

来源字段里的 `research/...` 路径指历史采集缓存。那些原始 HTML、完整 API 响应和大体积核心导出不作为本仓库内容；不会承诺单靠当前网页可以还原所有历史快照。本仓库提供的是**已审核映射到运行词典的可复现离线构建**，不是网页抓取流程的逐字节复现。

## 当前核验范围

- 1282 条界面译文；719 个 PoB 技能 ID 对应 718 个不同国服名称。
- 3427 个通用词缀模板；额外收录 672 个装备专用模板。
- 4540 个当前树非装饰节点名称，包含基础效果及版本限定的替代选项。
- 1768 个基底；447 个传奇名称与基底组合；287 个增幅器、26 种液化情感及 32 个类别。

这些是指定快照的收录／核验数，不代表当前游戏所有数据或未来版本始终全覆盖。测试产生的运行时覆盖输出不提交进仓库。
