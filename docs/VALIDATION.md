# 仓库整理验证记录

日期：2026-09-15。源码来自已有 v0.6.2 插件；测试平台为 Apple Silicon macOS，核心 0.23.1。以下结果对应本次测试平台与核心版本。

- 19 项安装器临时目录测试通过：幂等、缺失资源拒绝、回滚、卸载、更新覆盖检测、偏好保留。
- Noto 图集覆盖当前全部 2424 个所需字符；1282 条界面译文检查通过。
- 词典重复编译结果一致；天赋合并来源摘要和国服优先规则通过验证。
- 使用原版 App 实际 LuaJIT 运行基础界面和游戏文本测试。
- 使用 0.23.1 实际核心在合成配装中运行八个页面、控件、装备／技能／天赋搜索及属性比较回归。
- 157 个属性标签、772 个实际比较用例通过；切换中英文前后计算输出与导出保护检查通过。
- 新参数化打包器生成含 1550 个经过 manifest 校验的核心文件和 15 个中文资源的 App，ad-hoc 签名验证通过。本轮打包验收范围为 App 生成与签名校验。
- 独立插件 ZIP 的清单和 CRC 检查通过；Git 索引按源码发布清单核验通过。

本轮本地 Lua 测试使用实际 Mac 库；远程 Linux LuaJIT 测试结果见 [GitHub Actions](https://github.com/snipernan/pob2-zh-cn/actions/workflows/checks.yml)。本轮覆盖本机库、核心控件及打包流程；输入法候选窗口与跨 macOS 兼容性另按实际交互验收。
